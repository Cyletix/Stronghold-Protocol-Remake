# 变更影响

从当前请求/任务的目标、允许范围和验收条件出发，只查完成本次变更实际依赖的资产，不另造目标或强制普通修复创建 task。

沿直接改动向外核对：
- 契约与消费者：API、协议、schema、调用点、CLI 和配置。
- 状态：归属、序列化、存档兼容、迁移和缓存。
- 派生资产：生成源码、数据、报告、fixture 及其生成器。
- 验证与说明：对应测试、用户入口、规格和维护文档。

依赖须有引用/构建链/状态读写证据，不因目录相邻就全仓扫描。只说明实际必须同步的改动与验证；必要配套修改沿用现有授权，独立扩大的目标另行判断。

## 项目常见传播

- 模式源码在 `web/mode/`，`web/mode.js` 是生成物；按实际接口查引擎、UI、主机 VM、保存恢复和相关 smoke。
- 数据源/提取器变化：查对应 `web/` 产物、目录指纹、生成报告和 `docs/research/data-inventory.md`。
- 清单路径/生成逻辑变化：保留稳定 review ID、依据摘要、勾选和记录，同时核生成器、文档链接检查。
- supervisor schema 变化：核任务协议、脚本、RUNBOOK、任务/日志/收件箱与回归；一般文档整理不改变已有任务状态。

实际依赖已闭合、相关检查通过后停止扩查；新失败或新证据再打开对应问题。
