# 调查断点笔记（非状态源）

存放 `automaintain` 执行某 unit 时的调查中间结论，供会话 / 终端中断后快速续上，避免重复调查。

- 命名：`<TaskId>-<UnitId>.md`，如 `T-002-U-003.md`。
- 由 agent 在调查“证据充分”时写入，每获得一项新证据即更新；若 unit 无显式验收条件，先把写出的验收定义记入。
- 内容：收敛门禁 4 行判据（完成判据 / 数据字段 / 消费路径 / 是否已消费）+ 关键证据（字段值 / 代码位置 / 资源 / 尚未验证差异 / 下一步）。
- 不参与 `Validate` / `supervise.ps1` 状态机，可安全删除。unit 完成后可删除，或留存作审计。
