# 提取并复现系统性玩法规则

## 目标

- 依据现有数据、客户端资源/代码和可重复实验，补齐商店经济、策略、技能、天赋、召唤物、额外道具、阻挡与复活等系统规则。

## 任务范围

允许修改：
- 对应 `tools/**` 提取程序和生成数据
- `web/**` 规则实现与验证
- `docs/data-inventory.md`、`docs/data-progress.md`、`docs/findings.md`、`docs/mode-spec.md`、`docs/architecture.md`

明确不在本任务内：
- 与系统规则无关的视觉重做
- 先于规则稳定进行的大规模模块拆分

## 验收条件

- 每类规则均有来源字段、语义模型、边界、证据等级、代码 consumer 和可执行验证。
- 数值单位、触发时机、回合边界与例外不依赖无来源的近似值。
- 数据已提取但未接入、已接入但未验证的状态被明确区分。

## 依赖与约束

- 详细用户原话以 `assets/todo.md` 中各 source ID 为准。
- 玩法规则变更使用 `mode-spec-review` 与 `research-evidence`；公共规则执行器或数据结构变更使用 `change-impact`。

- [x] `U-STRATEGY` 提取并复现策略效果
- [x] `U-OPERATOR` 提取并复现技能、天赋、阻挡和复活规则

- [x] `U-VERIFY` 为系统规则补齐正例、边界和反例验证
- [x] `FINAL` 验收系统规则的证据与代码闭环
