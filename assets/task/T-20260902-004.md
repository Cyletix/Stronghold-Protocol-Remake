# 提取并复现敌人战斗行为

## 目标

- 从敌人数据、客户端行为和可重复实验中复现移动、索敌、攻击动作阶段与复杂敌人机制，消除不动和远程敌人持续原地攻击等基础行为偏差。

## 任务范围

允许修改：
- 敌人相关 `tools/**`、生成数据和 `web/**` 战斗逻辑
- `docs/data-inventory.md`、`docs/data-progress.md`、`docs/findings.md`、`docs/mode-spec.md`
- 敌人行为 smoke 与可重复实验

明确不在本任务内：
- 地图分区和镜头结构重做
- 与敌人行为无关的 UI 细节

## 验收条件

- 移动、攻击抬手、攻击、后摇、攻击间隔和恢复移动构成明确状态机。
- 普通远程敌人与确有特殊驻留机制的敌人依据数据或证据区分。
- 不动、持续原地攻击和复杂机制均有可复现测试场景，未知机制不以名称启发式冒充 Verified。

## 依赖与约束

- 详细用户原话以 `assets/todo.md` 中各 source ID 为准。
- 研究事实遵循 `research-evidence`；跨引擎状态结构修改使用 `change-impact`。
