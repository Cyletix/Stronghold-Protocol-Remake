# 修复局部交互、表现与素材缺陷

## 目标

- 在研究主干、可玩闭环和系统规则之后，集中修复不会改变总体规则模型的局部交互、表现、素材与失败反馈问题。

## 任务范围

允许修改：
- 对应 `web/**`、素材提取 `tools/**`、生成资源和局部 smoke
- 必要的视觉对照说明

明确不在本任务内：
- 改写地图阶段或系统性玩法规则
- 与列出缺陷无关的统一重设计

## 验收条件

- 每条 source 反馈都有独立复现步骤与修复证据。
- 素材问题优先追溯资源和提取链，视觉行为与用户原话一致。
- 局部修复不破坏主线任务已经固定的地图、镜头、候选区与规则契约。

## 依赖与约束

- 详细用户原话以 `assets/todo.md` 中各 source ID 为准，不在任务正文改写。
- 若局部问题实际暴露系统规则错误，应转交相应 P0/P1 任务，不在本任务扩张范围。
