# 确立纯 Web 复刻架构并完成性能与模块整改

## 目标

- 停止私服路线，以纯 Web 单机复刻为唯一产品目标；建立可支撑大量敌人、高攻速、大范围攻击、粒子特效和四人同屏的模块边界与性能预算。

## 任务范围

允许修改：
- `web/**` 游戏状态、规则、渲染、输入、UI 入口与数据消费者
- `tools/**` 性能基准、smoke、生成物检查与本地运行工具
- `docs/architecture.md`、`docs/mode-architecture.md`、`docs/research-workflow.md` 及直接相关说明
- 与本任务直接相关的依赖配置和测试资产

明确不在本任务内：
- 官方客户端补丁、登录协议、私服账号/房间/结算接口
- 在规则证据不足时臆造复杂玩法数值
- 与架构和性能无关的逐像素 UI 美化

## 验收条件

- 文档与运行入口统一表述为纯 Web 复刻，私服代码不再是产品主路径。
- 游戏状态、规则、战斗模拟、地图渲染、表现/UI 具有明确依赖方向，不再依靠无边界的双向全局回调扩张。
- 建立可重复性能场景，覆盖大量敌人、高频攻击、大范围查询、粒子和四块战场，并给出帧耗时与对象上限。
- 渲染只处理可见对象，模拟使用空间索引或等价方案，粒子/弹道具有对象预算和池化策略。
- 现有单机核心循环、候选区、地图切换、商店和战斗 smoke 保持通过。

## 依赖与约束

- `web/*.json` 仍是提取数据生成物，重构不得静默改变其 schema。
- 忽略目录中的 OBB、GameData、头像、立绘和 UI 导出物是只读输入；不得执行 `git clean -fdx`。
- 整改前快照为 Git 标签 `pre-web-refactor-20260905`，提交 `7a8725c`。
