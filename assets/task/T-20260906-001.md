# 修复立绘技能加成显示、三合一奖励与商店展开收起

## 目标

- 立绘面板技能页显示真实的技能加成数值（攻击/防御/生命/攻速等百分比，来自 skill_data effects 算子），不再全 0%。
- 三合一合成精锐后弹出「晋升调配特许」奖励：商店切换显示 3 个比当前调度中心高一阶的随机干员，玩家选 1 个加入候选区后恢复商店原页面。
- 商店展开/收起在整个右侧卡片上生效，不再只在下端一小格；冻结/刷新按钮点击不误触展开收起。

## 任务范围

允许修改：
- `web/mode.js`、`web/index.html` 及直接相关渲染逻辑
- 相关 smoke 验证

明确不在本任务内：
- 与这三项无关的 UI 重设计
- 架构拆分

## 验收条件

- 技能页显示加成百分比（如「攻击力 +30%」），数值与 effects 算子一致，不再全 0%。
- 合成精锐后出现奖励选择（3 个高一阶随机干员），选择后加入候选区、商店恢复原页面。
- 点击右侧卡片任意处（除冻结/刷新按钮）可展开/收起商店；冻结/刷新按钮点击不误触。
