# 干员基础行动：实现与缺口

更新：2026-09-14。覆盖基础医疗行动及本轮12个医疗专属技能；个体完成记录维护在实施清单。

根因是引擎只有敌方目标普攻循环，职业模板和技能文字分类不能替代职业分支特性。现在由 `tools/build_basic_attacks.js` 从 `character_table.json` 的 `profession/subProfessionId/description/trait.candidates` 导出 `web/basic_attacks.js`；普通、精锐按模式养成阶段选择黑板参数，经 `finalizeOperator → boardView → engine` 使用。454 份配置是源角色目录数量，不表示这些角色全部可招募或全部技能已还原。

## 已接入

以下分支与倍率为 **[Verified 源数据]**；模拟中的目标排序、触发先后及表现另按下文注明。

| 分支 | 当前行为 |
|---|---|
| 医师、疗养师 | 普通行动治疗范围内伤员，不发射敌方目标弹道；使用攻击力及攻击速度增益，治疗不超过生命上限 |
| 群愈师 | 每次最多治疗 3 名不同伤员 |
| 链愈师 | 从首名治疗目标跳跃，按源 `attack@chain.max_target/atk_scale` 限制人数与衰减，不重复跳跃 |
| 行医 | 治疗同时回复元素损伤；生命全满但存在元素损伤时仍可治疗；哈洛德当前技能按元素损伤排序并消费源回复倍率 |
| 吟游者 | 不普攻，范围内持续生命回复，基础源倍率通常为每模拟秒攻击力的 10%；这类回复可作用于禁止直接治疗的角色 |
| 咒愈师 | 保留法术攻击，造成伤害时按源倍率治疗范围内一人；普通弹道实际命中才触发，技能直接伤害也走同一出口 |
| 护佑者 | 通常法术攻击，技能期间改治疗，倍率读源 `heal_scale` |
| 阵法术师 | 未开技能不攻击，源防御/法抗加成生效；技能期间取消这部分加成，并攻击范围内所有敌人 |
| 解放者 | 未开技能不攻击、不阻挡，按源时间上限积累攻击加成；技能期间保留蓄积，结束或阵亡重置 |
| 武者、不屈者、收割者 | 排除外部直接治疗；武者命中回复自身，收割者范围攻击及按阻挡数限制的命中回血已接入 |
| 凝滞师 | 普攻命中施加短暂停顿；时长读源黑板 |

直接治疗统一排除阵亡、未到部署时刻、范围外目标；满血时不空耗行动冷却，行医的元素损伤目标除外。治疗范围使用实际朝向格，不以远程部署位置或“半径+1”代替。技能治疗也服从直接治疗限制。共享战场的两名玩家均视为友方，可以在有效范围内互相治疗。

流明当前技能已修复为：普通治疗不扣弹药，治疗异常状态目标才增强治疗、解除已接入的眩晕/睡眠/冻结并扣弹药。纯烬艾雅法拉当前技能接全场、5 次治疗及源倍率；每轮多发治疗优先不同目标。浊心斯卡蒂当前三技能替换普通回血，改为每秒扣血、范围真实伤害及攻击鼓舞，吟游者不吃鼓舞；魔王当前三技能的基础回血倍率使用源黑板。

同时消除了医疗技能分类器把“友方受到伤害”解释成对敌群攻的错误。下表的医疗技能改为按精确ID执行，替换旧文字分类；治疗仍用短绿色连线与恢复标记，由权威模拟产生，浏览器显示。

这组共12技能、10名资料身份。固定商店实际可用者按源季节单独核：华法琳/白面鸮两季，亚叶/瑰盐初版，调香师/录武官盟约II，共16个普通/精锐变体；其余以资料库账号路径验证，不因执行器存在而新增固定商店身份。

**[Inferred：社区规则佐证]** [PRTS 白面鸮](https://prts.wiki/w/白面鸮)给出固定秒数减间隔，[PRTS 清流](https://prts.wiki/w/清流)说明S2按0.12乘间隔，两者不能共用加法。[PRTS 华法琳](https://prts.wiki/w/华法琳)明确额外回复先于普通治疗；低于50%的条件在该次治疗前判断。[PRTS 苏苏洛](https://prts.wiki/w/苏苏洛)与本地源描述均限制同次作战两次；卫戍每轮战斗重建计数、同轮原地复活保留次数是此实现的对应约定。

次治疗技能只在有合法伤员且到达治疗行动时消耗一份充能，不允许手动提前空放；用来消耗技能的治疗不立即为自身补一份攻回SP。持续技能沿用卫戍既有满SP自动施放，不新增另一套手动操作。所有新技能不会伤害敌人；排除禁止直接治疗、死亡、尚未部署和范围外对象，范围内可治疗队友。

边界：此批不代表10名干员的全部技能、天赋、模组和特殊治疗加成都完成。清流继续沿用距离大于2格的疗养师衰减近似；两项技能只勾明确的主体子项，完整技能仍待范围图/组件核对。精确治疗前后摇、完整禁疗来源与全体天赋联动另核。

`node tools/_medic_skills_smoke.js` 验证120份等级执行、16个实际赛季变体与12次主机两名玩家归属的鉴权恢复。包含实际治疗量/人数/范围/间隔、次数上限/真实原地复活/下一战重置、充能与条件/满血、取消旧开场治疗、SP锁/结束清理、随机目标RNG及调香师已有全场回复联动。脚本通过不作为原版完整还原的证据。

## 持续治疗与失血增益（2026-09-14）

沿用 [medic-skills.js](../../web/src/simulation/medic-skills.js) 的有限技能ID入口，新增嘉维尔S1/S2、华法琳S2。**[Verified：本地源字段]** 三项各1–10级的倍率、充能、SP和逐秒间隔来自 `skill_table.json`；源技能 `duration=-1 / durationType=NONE` 与黑板中的效果持续时间分开处理，不能让干员永久停留在技能期间。固定商店只含两季华法琳普通/精锐4个变体；嘉维尔通过资料库入口验证，不额外加入固定商店。

| 技能 | 当前执行主体 |
|---|---|
| 嘉维尔 S1 活力再生 | 普通治疗时消费一份充能，保留当次直接治疗，并给目标附加定时治疗；不触发技能开启/结束或盟约的释放技能事件 |
| 嘉维尔 S2 活力再生·广域 | 给范围内所有可直接治疗友方附加定时治疗，含满血单位；附加效果期间仍能普通治疗和自然回复SP |
| 华法琳 S2 不稳定血浆 | 自身及范围内随机一名其他友方获得源攻击加成和最大HP比例失血；无队友只施加自身，友方召唤物可被选中；失血绕过防御与伤害盾，不发出受击事件、不回受击SP |

**[Inferred：社区佐证]** [PRTS 嘉维尔](https://prts.wiki/w/嘉维尔)说明两项增益缓存施加瞬间攻击力、逐秒产生治疗，S1没有技能开启/结束事件，S2仍受禁疗约束；因此使用定时治疗，不能当作无视直接治疗限制的生命回复。[PRTS 华法琳](https://prts.wiki/w/华法琳)说明无其他目标也可开启，并提示实际失血略低于标注值；当前使用本地源每秒比例，没有凭空添加修正系数。

目标保存 `medicEffects` 的施加时间、已结算跳数、来源玩家/单位、攻击快照和到期时间。施加者退场后目标效果继续；目标死亡、战术支援点休眠或傀儡转形时清理，下轮战斗重置。攻击增益沿用公共属性加算层，用独立来源键去重。随机队友共用可恢复RNG；治疗沿用绿色恢复反馈，失血增益施加时显示短红色上升标记。

**[仿真约定，未作为原版事实验收]** 首次在施加后一个源间隔结算，末跳包括持续时间端点；嘉维尔每跳前重新判断是否严格低于半血；同施加者同技能刷新效果，不增加层数，不同施加者独立。源端没有给出重复施加、生命阈值的具体检查时点或首末跳帧相位，这些待客户端组件/视频核对。失血归零走既有死亡/不死/替身流程；完整禁疗/孤立来源及嘉维尔模组的条件治疗加成仍未补全。三项完整技能保持未勾，只验收明确的主体子项。

`node tools/_periodic_medic_smoke.js` 覆盖30份真实账号等级、4个实际赛季变体、三项主机两玩家归属的认证恢复；检查攻击快照、半血边界、本地叠加约定、整段与分段跳数一致、满血/范围/禁直接治疗、消费充能而不发技能事件、失血绕过伤害盾、真实死亡复活/不死/傀儡转形/支援点撤退及新战斗重置。每个验证范围写入原有[干员表](../checklists/operator-checklist.md)或[资料库表](../checklists/library-checklist.md)，不把脚本通过当作原版帧级还原。

| 莎草 S2 | 锁定范围内另一名最高生命上限可直接治疗友方，含召唤物；源加攻、固定秒数减间隔、增加一次链跃；没有合法对象不空放。目标真正退场立即结束，生命上限排名变化不重新选人 |

**[Inferred：社区佐证]** [PRTS 莎草](https://prts.wiki/w/莎草)说明屏障量不叠加、可抵消伤害，S2选定对象退场会结束，无法选到对象则不施放。[PRTS 录武官](https://prts.wiki/w/录武官)的S2描述与本地黑板一致：治疗后限时获得每次受伤回复，不能当作普通定时回血。链治疗可以传向满血友方；具体跳跃几何仍是下节注明的近似。

运行时将 `medicBarrier`、`medicReactions` 放在受益单位上，将锁定对象的玩家/单位/部署代次放在技能状态内。屏障在生命扣减前消耗；伤害小字报告实际生命损失，受伤回复在这之后单独结算。目标真正死亡、支援点休眠或傀儡转形清空效果，施加者死亡不移除已附加给别人的效果，新战斗不继承。共享战场/主机恢复保留玩家归属；屏障有浅蓝色短条，复用既有治疗反馈。

**[仿真约定，待取证]** 重复屏障保留较大剩余量并刷新时长；同源受伤回复刷新、不同来源分别生效；致命伤不先靠回复救活，死亡防止与延迟伤害等特殊排序另核。锁定治疗允许满血主目标继续治疗并链跃；主目标移动到范围外暂不治疗，不改锁其他人，退场才结束。上述覆盖优先级、多副本叠加、精确时序和完整模组联动均不勾为原版完整技能。

`node tools/_protective_medic_smoke.js` 核30份真实账号等级、10组实际赛季普通/精锐、6份天赋候选和3次主机两玩家鉴权重放；包含真实抵伤、治疗/链跃人数、目标锁定/无目标、满血/禁直接治疗、源间隔、持续/SP结束、伤害后回复、到期/死亡/变形/战斗重置和浅蓝条绘制参数。三项只验收限定主体，完整技能和天赋主条继续保留边界。
