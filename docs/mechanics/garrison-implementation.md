# 卫戍协议干员特质接入（2026-09-12）

本页只记录干员的 garrison 特质，不把普通职业特性、技能、天赋、盟约本体效果都算作已完成。

## 源数据与覆盖范围

[Verified / 客户端数据] `activity_table.json` → `activity.AUTOCHESS_SEASON.{act1autochess,act2autochess}` 的 `charShopChessDatas`、`charChessDataDict[].garrisonIds`、`garrisonDataDict`。普通与精锐分别按实际棋子 ID 引用，不能只读取普通变体。初版 200 个、盟约 II 266 个棋子变体均保留；其中包含隐藏和原型条目，不等于游戏名册新增了这些干员。敌人种族来自 `enemy_database.json` 的 `enemyTags`，不把所有飞行敌人都当无人机。

构建：`node tools/build_garrison.js` → `web/garrison_data.json`。执行：`web/mode/garrison.js` → `tools/build_mode.js` → `web/mode.js`。客户端、房主运营、共享战斗都消费同一份目录；目录加入存档和联机版本指纹，避免旧新规则混用。

## 已接入的执行路径

以下为实现状态；通过模拟器测试不能反证原作所有边界完全一致。

| 路径 | 执行与边界 |
|---|---|
| 获得、出售 | 普通/精锐变体；自身/指定/随机/最高层盟约叠层，按调度中心等级叠层；下轮资金；免费刷新；固定干员/装备奖励；免费特殊招募 |
| 进入与结束休整 | 场上条件、同一行人数；候选区例外；前后方、整列、候选区、不同等阶；本轮获得/消费/刷新计数；奇数轮装备奖励 |
| 特质传递 | 给身前一格、同排最右、所有指定盟约成员；仅本场有效；复制休整事件和触发其他干员的获得/结束事件；触发链防循环 |
| 战斗叠层 | 击杀（包含直接技能伤害）、开技、阵亡、部署/再部署；阈值、概率、单场上限；逗号分隔的多个盟约；前方增量放大 |
| 属性 | 固定攻血、按层数的攻防血/攻速/生命与技力恢复、再部署缩减、100 秒部署基础属性；重复计算不重复乘算 |
| 伤害 | 弱点伤害在物理/法术中择优；按无人机/海怪标签增伤；束缚或停顿状态增伤 |
| 合成与展示 | 源 `upgradeNum` 支持风丸两张合成；合成保留最多两件装备，多余返库存；特质与装备分为两个页签；绝技仅列场上贡献该盟约的精锐 |

叠层保存到 `G.addLayers`，跨准备/战斗及回合保留；事件的单场次数单独保存在 `G._gar`，新战斗清零。获得而未激活的层数保存，但不视为已激活；战斗中要求“已激活”的效果不会绕过人数条件。`_garrisonRoundGained/Spent/Refresh` 每轮清零，免费刷新次数及下轮资金按各自生命周期保存。

[Inferred / 时序约定] 第三份合成时，按实际生成的精锐棋子执行一次精锐“获得时”，不额外创建并触发被消耗的第三张普通棋子；同层最多/同人数最多的并列对象按 ID 稳定排序。此类精确服务器顺序仍需录像或客户端实现核对。

[社区资料交叉核对] 联防不能叠层，源文案也按“已激活”描述战斗特质；共享联防禁用叠层，Boss 保留每名玩家自己的归属。参见 [PRTS 卫戍协议：盟约](https://prts.wiki/w/卫戍协议：盟约) 的同盟模拟说明。本项目模拟器通过双玩家归属与重连快照测试，不等于跨网实测。
