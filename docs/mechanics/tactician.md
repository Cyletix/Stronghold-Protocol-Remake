# 战术实体：七名战术家的独立机制

本批按实体分别实现；风丸纸偶见[纸偶与傀儡师专项](dollkeeper.md)。纸偶是独立技能召唤物，傀儡师本体转替身是另一套状态机。共用生成、归属、退场与保存机制不等于共用攻击、天赋或技能。

## 樱桃、牙猎犬和指挥中心（2026-09-13）

**[Verified：源字段]** `character_table.json` 的 `char_4147_mitm` / `char_4215_buddy` / `char_4228_closur` 与对应 `token_10037_mitm_trshrb` / `token_10063_buddy_bddg` / `token_10066_closur_ourbase`；技能及模组分别取 `skill_table.json`、`battle_equip_table.json`。生成器保留全部技能等级、token天赋范围和独立被动范围，缺模组不会凭空生成。运行时为明确skillId白名单，未知黑板报错，不回退为通用攻击增益。

- 樱桃主点被击倒或手撤，下一30Hz逻辑帧在四邻合法空位生成残骸。残骸半血、零攻防、阻挡1、不能攻击或复活，主点恢复不会删除已有残骸；主人离场回收全部。S1按本体攻击在樱桃处造成物伤后转战术点，缺主点仍给6费；S2只增益主人及主樱桃，12费分15秒回复，结束销毁主点。Y模组提供165%特性、所阻挡敌人优先级及65%/70%残骸生命。没有将未确认的`mitm_s_2[to_token].hp=1`猜成额外满血治疗。
- 隐秘队没有技能。前三个不同敌人的首次攻击替换为挂弹，其他有来源的友方伤害才能引爆，包含牙猎犬；本体和无来源伤害不能引爆。六档潜能独立选源倍率/眩晕，单弹返1费，30秒到期消失。牙猎犬仅普攻自身阻挡者，落地斩击周围8格最多3目标且可对空，60秒恢复再次触发。隐秘队本体不计普通干员部署上限；召唤物本来就不占该上限。
- 指挥中心允许全部部署位，不攻击、基础阻挡2；S1/S2/S3支援范围分别为源`x-5`、`x-4`、`x-6`（5/9/9格，最后一项是长十字，不是13格菱形）。范围内友方含召唤物成为其援军，中心休眠或主人离场即失效。S1护盾不叠加，按施放次数逐步提高回费并在重新部署时清零，首tick半间隔。S2动态增防/阻挡、双目标、对援军阻挡者越界选敌；部署时按当前部署费用40%向上取整，下一帧返费，只结算一次。普通准备阶段移动不触发战斗部署返费。
- S3合并本人、中心和援军原始范围，流形只贡献基础范围；每9次攻击增加一目标，上限是7目标（6次增加）。迟钝同源叠加/刷新、异源取最大，影响普通移动/攻击、已支持的寒冷/冻结/眩晕/睡眠/沉默时钟；自己的3秒持续和持续伤害触发频率不变。特殊Boss动画与尚未接入的状态/技能时钟未验收，不能据此勾完整迟钝系统。
- 携带可露希尔含候选区，使本席罗德岛干员获得源攻击增益，并降低部署费用下限。负费用时自然恢复减半，技能回费保持原值；99封顶规则不变。X模组按源等级提高携带增益/下限，援军仅对自己所阻挡敌人的伤害获得15%减免。初始免费布阵、准备阶段预设战术点和自动施法仍是本项目适配，不证明这些资料库角色属于原版两季卫戍商店。

## 夜半与公共规则补全

**[Verified：本地源字段]** `character_table.json` 的 `char_476_blkngt` / `token_10021_blkngt_hypnos`、`skill_table.json` 的 `skchr_blkngt_1/2`、`battle_equip_table.json` 的 `uniequip_002_blkngt` 提供阶段属性、20/17/15秒恢复周期、x-5攻击格、SP、充能、技能倍率和模组黑板。四名战术家导出全部技能等级；进入战斗与资料库技能文案都按实际等级读取，不再一律套技能4/7。卫戍固定配置仍遵循源养成表。

**[Inferred：采纳社区机制]** [PRTS 夜半](https://prts.wiki/w/夜半)与[眠兽](https://prts.wiki/w/眠兽)用于区分半醒的休眠和阵亡战术点，以及睡眠选敌、安眠溅射、形态切换清除睡眠的行为。安眠选区采用源眠兽x-5十字格；群体法伤以命中目标为中心半径1.1。后者不能拿来替代睡眠选区；十字边界的逐帧碰撞尚未取得客户端证据。

- 半醒立即获得11费，主人技能即时结束。眠兽休眠时不攻击、继续阻挡并按百分比回复生命；仅实际受伤后醒来，按所选等级获得10秒攻击与攻速增益。没有眠兽或只有阵亡战术点时只回费。
- 安眠立即获得4费，施加地面睡眠；眠兽优先攻击睡眠者、能够阻挡睡眠者，技能窗口内改为群体法伤，仅对睡眠目标使用额外倍率。飞行与源睡眠免疫排除，睡眠施加不受隐匿选中限制；这不等于眠兽可以攻击隐匿目标。
- 普通攻击、技能伤害和直接持续伤害尊重敌方睡眠无敌。眠兽拥有明确例外；没有把此例外扩散到夜半本体或所有地面干员。其他具有睡眠例外的干员仍需各自实现。
- 安眠记录每个战术点的施加来源，形态变化仅清除本点来源；另一名玩家或外部来源保留。战术点阵亡形态仍可施放安眠，到期恢复形态时解除自己施加的睡眠。状态、来源与时钟进入签名快照。
- 点梦使用源5%/10%增益和0.1秒检测，提供者死亡/出范围/解除睡眠立刻失效，等下一次检测才能更换；精确初次扫描相位仍采用仿真时钟。源模组阻挡减伤单独执行。
- 自动施法属于本项目自走棋适配：安眠的现存效果未结束时保留下一充能，避免连续两帧浪费充能；不改变源技能SP与持续时间。
- 豆苗Y模组的165%特性、援军所阻挡敌人的友方选敌优先级、阻挡时防御增益已接。它不是让敌人优先攻击磐蟹的嘲讽。
- 缪尔赛思携带减费按本席库存判断，候选区也有效；同类不叠加。初始布阵在本模式免费，首次额外折扣无费用可扣，不发额外费用；后续再部署使用源费用减2。修复 `finalizeOperator.cost` 未写回场上单位、导致再部署回退统一2费的遗漏。

## 当前可游玩的行为

- 主人布置到场上后，候选区出现独立战术点卡。拖到主人攻击范围内合法空格，再拖出格子确认朝向；费用0、不占干员名额和盟约人数。准备时可移动/撤回布置；开战只按玩家指定位置部署。未预先布置时，主人完成部署后仍可从候选区拖放。狼群/磐蟹不能放高台，流形可用全部部署位；红色提示与实际拒绝共用检查。
- 援军阻挡与攻击使用自身属性。飞行敌人不占阻挡；由本体认定的援军触发150%攻击；指挥中心可将范围内友方登记为本体援军。狼群致死先减层，耗尽后转休眠；休眠无阻挡、不可被普通攻击和治疗选中，到期满血返回。磐蟹和主流形各用自己的刷新周期，临时复制体死亡直接消失。
- 战斗中点击主流形，技力达到100时点“开启复制窗口”，20游戏秒内把本人的候选干员拖到流形上。候选保留，不会上场或消耗。可主动取消；超时或主人开技能会取消，重新积累技力；主人技能期间不能开启窗口。允许再次充能后重新复制。旧准备下拉框和自动复制已移除，旧存档偏好不触发新技能。
- 流形只携带白名单属性，不复制目标的技能、天赋执行器、群攻、治疗、储存能量等分支机制。近战偷取攻防为最终加算；远程以独立攻击弹道实现S2逐发随机选敌。分裂临时体不继续分裂、不转休眠。S3远程刷新临时体并附带束缚，近战眩晕自己阻挡的敌人。
- 主人离场清除其援军及临时体；普通技能结束不误删永久援军。狼影层数、休眠时间、流形复制属性、分裂计数、临时体寿命与归属随战斗快照恢复。新实体带自己的简易标记、血条和休眠倒计时。
- 主动撤退与致命伤害分开处理：狼群主动撤退清空全部狼影，主磐蟹/主流形转战术点恢复；不回候选区，到自身周期末原位满血返回。休眠战术点不能再撤退。临时复制体、纸偶等现有独立技能召唤物退场后消失；傀儡师转替身仍是另一类状态机。主人自动再部署沿用指定战术点位置，非法位置留候选等待玩家布置。
- 本地与主机共用 `game/tactical` 操作检查；战斗期间只开放这些召唤物操作，普通干员移动和商店仍锁定。Boss右侧战术点与朝向一起镜像，按席位校验复制对象，断线暂停禁写。快照保存复制窗口、冷却和形态，恢复不重复执行。
- 主人准备阶段撤回候选区时收掉战术点；跨普通/Boss区段的阵型迁移同步移动指定坐标。新地图落点不合法时回到召唤物候选，重复刷新不会再次偏移。

## 明确保留的差异

- 2026-09-13按用户纠正撤销自动选点约定，采纳PRTS机制说明：可部署战术点、原位恢复与20秒复制窗口。准备时保存战术点阵型是本项目自走棋适配，不据此证明客户端全部阶段操作限制。
- 流形S3按源小力度0与重量差，参考[PRTS 拉力表](https://prts.wiki/w/游戏数据基础/en)的测量终点，差≤-3不移动，-2最多0.03格、-1约初始距离35%，其余拉近至阻挡位置。这是 **[Inferred] 终点近似**，没有复现Unity逐帧受力、摩擦与碰撞，其完整拖拽子项保持未完成。可部署的围墙格不视为敌人可通行格，拖拽按 `passable` 检查路径边界。
- 原始技能间隔有取整差：持续回费在不足一个30Hz逻辑帧的末tick误差内归一到源总费用；连击动作帧、前后摇和精确首次tick未还原。流形S1按源持续和总费用均匀安排tick。
- 其他模组/潜能组合、复制面板受所有装备/盟约/天赋影响时的精确层级仍未完成；七名分支范围见上表。
